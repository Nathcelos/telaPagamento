# 💳 Tela de Pagamento

Projeto desenvolvido como atividade prática do curso Senac EAD, utilizando HTML, CSS e JavaScript.

## 📌 Sobre o projeto

A página simula uma tela de pagamento de uma loja virtual, permitindo escolher entre Pix e cartão de crédito, com cálculos automáticos de descontos, juros e parcelas.

## ⚙️ Funcionalidades

- Seleção entre Pix e cartão de crédito.
- Desconto de 10% para pagamentos via Pix.
- Identificação da bandeira do cartão pelo número informado.
- Validação do número do cartão.
- Cálculo de juros para pagamentos parcelados.
- Atualização automática do valor total.
- Mensagem de confirmação ao clicar em Pagar.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 🎯 Objetivo

Praticar a criação de páginas web, a manipulação de elementos HTML com JavaScript, o uso de eventos e a implementação de cálculos e regras de negócio.
